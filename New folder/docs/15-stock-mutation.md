# 15 Stock Mutation

## Tujuan

Memindahkan stok dari satu lokasi ke lokasi lain tanpa mengubah total quantity.

## Contoh

```text
RAK-A03 → RAK-A07
500 KG
```

## Hasil

```text
A03 = -500 KG
A07 = +500 KG
Total stok = tetap
```

## Data

- nomor mutation
- tanggal
- item
- batch
- quantity
- source location
- destination location
- reason
- user
- status
