# 10 Material Request

## Tujuan

Mencatat kebutuhan bahan dari produksi.

## Alur

```text
Draft
 ↓
Submitted
 ↓
Approved
 ↓
Picking
 ↓
Issued
```

## Data

- nomor
- tanggal
- requester
- department/production
- detail item
- quantity
- tujuan
- status
- catatan

Quantity aktual saat picking/outbound harus dapat berbeda dari quantity request jika proses lapangan mengizinkan.
