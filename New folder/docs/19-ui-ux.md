# 19 UI/UX

## Prinsip

- Sederhana.
- Cepat digunakan warehouse.
- Desktop-first bila perangkat utama komputer.
- Responsive.
- Form transaksi tidak terlalu panjang.
- Status transaksi terlihat jelas.
- Jangan menyembunyikan informasi penting.

## Halaman utama

```text
Dashboard
Master
Procurement
Inbound
Inventory
Outbound
Reports
System
```

## Form transaksi

Gunakan pola:

```text
Header
 ↓
Detail items
 ↓
Summary
 ↓
Action
```

## Status

Gunakan label status yang konsisten.

## Konfirmasi

Posting transaksi yang memengaruhi stok harus meminta konfirmasi sebelum final.
