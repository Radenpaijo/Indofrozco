# 06 Purchase Request

## Tujuan

Mencatat kebutuhan pembelian sebelum PO dibuat.

## Alur

```text
Draft
 ↓
Submitted
 ↓
Approved / Rejected
 ↓
Menjadi dasar PO
```

## Validasi

- Barang wajib ada.
- Quantity > 0.
- Requester wajib tercatat.
- PR rejected tidak boleh langsung diproses menjadi PO.
