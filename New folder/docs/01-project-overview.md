# 01 Project Overview

## Nama Sistem

INDOFROZ Warehouse & Inventory Management System (WMS)

## Sasaran

Membantu pengelolaan administrasi dan pencatatan aktivitas gudang secara terstruktur.

## Ruang lingkup

### In Scope

- Master barang
- Supplier
- Gudang
- Rak/lokasi
- User dan role
- PR
- PO
- Receiving
- Pemeriksaan barang
- Penempatan barang
- Inventory
- Material request
- Picking
- Barang keluar
- FIFO
- Stock opname
- Adjustment
- Mutasi
- Laporan
- Audit log

### Out of Scope / TBD

- Integrasi ERP eksternal
- Integrasi timbangan
- Integrasi barcode scanner
- IoT suhu cold storage
- Automatic rack allocation
- Automatic purchasing
- Accounting
- Payroll

Fitur tersebut tidak boleh dibuat sebagai requirement tanpa keputusan client.
