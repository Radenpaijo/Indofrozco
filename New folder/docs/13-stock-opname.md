# 13 Stock Opname

## Tujuan

Membandingkan stok sistem dengan stok fisik.

## Alur

```text
Buat sesi opname
 ↓
Pilih gudang/lokasi
 ↓
Input quantity fisik
 ↓
Sistem hitung selisih
 ↓
Review
 ↓
Adjustment
```

## Formula

```text
Selisih = Stok Fisik - Stok Sistem
```

## Contoh

```text
Sistem = 1.000 KG
Fisik  =   980 KG
Selisih = -20 KG
```

Stock opname tidak langsung mengubah stok sebelum proses final/approval sesuai kebijakan client.
