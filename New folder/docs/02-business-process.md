# 02 Business Process

## A. Pengadaan

```text
Kebutuhan barang
 → PR
 → Approval
 → PO
 → Supplier
```

## B. Barang masuk

```text
PO
 → Barang datang
 → Pemeriksaan
 → Receiving
 → Penempatan
 → Inventory bertambah
```

## C. Barang keluar

```text
Kebutuhan produksi
 → Material Request
 → Approval
 → Picking
 → Verifikasi quantity
 → Barang keluar
 → Inventory berkurang
```

## D. Mutasi

```text
Lokasi asal
 → Mutasi
 → Lokasi tujuan
```

## E. Stock opname

```text
Stock opname
 → Hitung fisik
 → Bandingkan sistem
 → Selisih
 → Adjustment jika disetujui
```
