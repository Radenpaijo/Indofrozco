# 07 Purchase Order

## Tujuan

Dokumen pemesanan kepada supplier.

## Data

Header:

- nomor PO
- tanggal
- supplier
- PR reference
- status
- catatan

Detail:

- item
- quantity
- unit
- harga (TBD)
- subtotal (TBD)

```text
Draft
Submitted
Approved
Ordered
Partial Received
Completed
Cancelled
```

Status final harus mengikuti kebutuhan client.
