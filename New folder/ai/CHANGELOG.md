# CHANGELOG

Dokumen ini mencatat perubahan requirement dan keputusan project.

## Format

```md
## YYYY-MM-DD — Title

### Change
Apa yang berubah.

### Reason
Alasan perubahan.

### Impact
Database / backend / frontend / report.

### Status
Approved / Proposed / TBD
```

## Initial

Project documentation baseline dibuat sebelum implementasi agar Antigravity memiliki source of truth.
